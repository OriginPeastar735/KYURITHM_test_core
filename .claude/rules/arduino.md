# 専用コントローラー（`Arduino/slider32/`）

- Raspberry Pi Pico ＋ MPR121 ×4。環境は arduino-pico v6.3.0 / Adafruit_MPR121 v1.1.3
- 筐体のタッチ面（今の作り。将来はプリント基板の電極に置き換える予定）
  - 左斜面8キー・底面16キー・右斜面8キー。斜面の角度は45度
  - 電極は銅テープ。幅1cmのテープを2本並べ、幅2cmの電極にしてアクリル板に貼っている
  - 押せる範囲は縦10cm。電極と電極のすき間は5mm（電極の間隔は2.5cmごと）
  - 電極の上にはクリアファイルを貼っている（指は電極に直接触れない）
  - 電極と MPR121 はリード線をはんだ付けしてつないでいる。線の長さは5〜10cmでばらばら（できるだけ短くしてある）
  - MPR121 1枚が8キーを受け持つ（左斜面／底面左／底面右／右斜面）。ユニット2の5・7番目のキーだけ ELE8・ELE9 につないでいる（`ELE_MAP`）
- 1ms ごとに `0xAA` ＋ 4バイト（lane 0〜7 / 8〜15 / 16〜23 / 24〜31、各バイトの bit0 が一番小さいレーン）を送る。115200bps
- ポートは `InputManager` が自動で探す（`0xAA` のパケットが届くポートを選び、切れたらつなぎ直す）。`portName` は最初に試すポートというだけなので、合わせなくてよい
- Unity から 1文字のコマンドを受け取る（`0`〜`3`: そのユニットだけ再初期化 = F5、`r`: 全体の再初期化 など）
- **通信の形を変えるときは `slider32.ino` と `InputManager.cs` を必ず両方直す**
- Claude はマイコンに書き込めない。書き込みと動作確認は Arduino IDE でユーザーが行うので、その手順を伝える
