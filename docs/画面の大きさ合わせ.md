# 画面の大きさ合わせ

筐体に大きなテレビを使うとき、ゲームのウィンドウを小さくして、筐体のタッチセンサーの位置に合わせる機能。

ゲームを枠なしのウィンドウで表示し、その大きさと位置を変える。ウィンドウの縦横比はテレビの画面と同じなので、UIもプレイ画面も、センサーとの位置関係を保ったまま小さくなる。

- Windows用にビルドしたゲーム（exe）でだけ動く。Unityエディタで再生したときは、設定画面は出ず、ウィンドウも動かない
- ウィンドウの外にはデスクトップが見える。展示用PCの準備は[下の表](#展示用pcの準備)を参照

## いつ出るか

| 状況 | 動き |
|---|---|
| 設定ファイルが**無い**（初回起動） | オープニングの上に設定画面が出る。確定すると設定ファイルを保存してオープニングに進む |
| 設定ファイルが**ある**（2回目以降） | 設定画面は出ない。保存した大きさと位置のウィンドウで起動する |

設定ファイルの場所:

```
C:\Users\<ユーザー名>\AppData\LocalLow\DefaultCompany\KYURITHM\display_fit.json
```

ゲームのフォルダとは別の場所にあるので、新しいビルドに入れ替えても設定は引き継がれる。

## 合わせ方

1. ゲームを起動する。全画面で設定画面が出て、ゲーム画面の外枠（水色）とセンサーの位置（ピンクの線）が描かれる
2. PCのキーボードでウィンドウの大きさと位置を動かし、ピンクの線を筐体のセンサーに重ねる
3. センサーのどこかをタッチして確定する（キーボードの Enter でもよい）

### キー操作

| キー | 動き |
|---|---|
| ← → ↑ ↓ | 位置を動かす |
| Z / X | 小さく / 大きく（センサーのある下辺の中央を基準に変わる） |
| Shift（押しながら） | 速く動かす |
| R | 最初の状態（全画面）に戻す |
| Enter またはセンサーをタッチ | 確定して保存する |

- 大きさは 30%〜100% の範囲で変えられる。画面の外にははみ出さない
- 100% から小さくした瞬間に、全画面から枠なしのウィンドウに切り替わる
- キーを押し続けている間、ウィンドウは0.1秒ごとに動く（毎フレーム動かすと重いため）
- 開いてから1秒間は、センサーに触れても確定しない（うっかり確定しないため）
- 設定中は、オープニングはタッチに反応しない

## 展示用PCの準備

ウィンドウの外にはデスクトップがそのまま映る。テレビに余計なものが映らないよう、またタスクバーの焼き付き（特に有機ELテレビ）を防ぐため、次のように設定しておく。

| 設定 | 場所（Windows 11） |
|---|---|
| 壁紙を黒の単色にする | 設定 → 個人用設定 → 背景 → 「単色」で黒 |
| タスクバーを自動的に隠す | 設定 → 個人用設定 → タスクバー → タスクバーの動作 |
| 通知を切る（応答不可にする） | 設定 → システム → 通知 |
| デスクトップのアイコンを隠す | デスクトップを右クリック → 表示 → デスクトップ アイコンの表示 |
| 画面がスリープしないようにする | 設定 → システム → 電源 → 画面とスリープ |

ウィンドウの外をマウスでクリックしても、ゲームは止まらない（Player Settings の Run In Background がオン）。センサーの入力もそのまま届く。

## 合わせ直すとき

テレビや筐体の位置を変えたときは、次の手順でやり直す。

1. ゲームを終了する
2. 上の場所にある `display_fit.json` を消す
3. ゲームを起動すると、設定画面が出る

## 設定ファイルの中身

手で書き換えてもよい。値はどれもテレビの画面に対する割合。

```json
{
  "scale": 0.8,
  "left": 0.1,
  "bottom": 0.0
}
```

| 項目 | 意味 |
|---|---|
| `scale` | ウィンドウの大きさ（1 で全画面、0.3 まで） |
| `left` | ウィンドウの左端の位置（0 で画面の左端） |
| `bottom` | ウィンドウの下端の位置（0 で画面の下端） |

## 処理の重さ

増えない。ウィンドウを小さくすると描く解像度も小さくなるので、全画面のときより軽くなる。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 設定画面が毎回出る | 設定ファイルを保存できていない。Player.log に「保存できませんでした」と出ていないか確認する |
| ウィンドウに枠（タイトルバー）が付いたまま | 開発者に連絡する |
| ウィンドウが別のモニターに出る | ゲームを起動したモニターを基準に合わせる。テレビ側でゲームを起動する |

Player.log の場所: `C:\Users\<ユーザー名>\AppData\LocalLow\DefaultCompany\KYURITHM\Player.log`
